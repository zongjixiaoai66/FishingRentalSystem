# 项目简介
Vue.js+SpringBoot前后端分离新手入门项目《渔具租赁系统》，包括渔具档案模块、渔具租赁模块、渔具归还模块、在线留言模块和部门角色菜单模块，项目编号T005。

《渔具租赁系统》是一个基于Vue.js和SpringBoot的前后端分离新手入门项目，旨在帮助初学者快速掌握前后端分离开发技术。该系统主要包括以下几个模块：渔具档案模块，用于管理渔具的基本信息，如名称、类型、价格等；渔具租赁模块，实现用户在线租赁渔具的功能，包括租赁流程、租赁状态等；渔具归还模块，处理用户归还渔具的流程，包括归还状态、损坏赔偿等；在线留言模块，提供用户与管理员之间的在线交流平台，方便用户提出建议或反馈问题；部门角色菜单模块，实现不同角色（如管理员、用户等）的权限管理，确保系统安全性。通过这个项目，新手可以学习到前后端分离开发的基本流程、技术栈以及实际应用场景。
